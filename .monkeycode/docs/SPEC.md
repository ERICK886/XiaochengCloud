# 小程网盘 - 产品规格说明书

## 1. 项目概述

### 1.1 项目名称与定位

**项目名称**：小程网盘

**核心定位**：轻量化、高兼容、安全便捷的个人/小型团队云存储工具，参照百度网盘核心逻辑，主打"轻量不简陋、安全又易用"，区别于百度网盘的厚重，侧重轻量化使用场景。

### 1.2 目标用户

- 学生群体：备份学习资料（课件、笔记、真题）
- 职场人士：备份工作文档（报告、表格、合同）
- 小型工作室：团队文件共享与协作
- 普通用户：照片、视频、个人文件备份

### 1.3 核心价值主张

| 维度 | 百度网盘 | 小程网盘 |
|------|---------|---------|
| 安装体积 | 移动端>100MB, PC端>200MB | 移动端≤100MB, PC端≤200MB |
| 操作层级 | 复杂层级 | 核心操作一键可达 |
| 会员价格 | 高 | 低，性价比高 |
| 团队功能 | 繁杂 | 轻量化，简单易用 |

## 3. 基础存储功能（核心模块）

### 3.1 文件上传/下载

| 功能点 | 规格说明 |
|--------|---------|
| 支持格式 | 文档、图片、视频、音频、压缩包、安装包等全格式 |
| 单文件上限 | 10GB |
| 断点续传 | 支持，网络中断后自动恢复 |
| 批量操作 | 支持批量上传/下载 |
| 进度显示 | 实时显示上传/下载进度，可暂停、取消 |
| 网络适配 | 适配 WiFi、4G、5G，优化弱网传输稳定性 |

### 3.2 文件管理

| 功能点 | 规格说明 |
|--------|---------|
| 文件夹操作 | 创建、重命名、移动、删除、复制 |
| 搜索功能 | 关键词搜索 + 分类搜索（图片/视频/文档） |
| 排序方式 | 按大小、修改时间、创建时间排序 |
| 收藏功能 | 常用文件一键收藏 |
| 最近文件 | 最近文件快速查看入口 |
| 回收站 | 删除文件保留30天，可恢复或彻底删除 |

### 3.3 文件列表交互

- 列表视图 / 网格视图切换
- 文件缩略图预览（图片、视频封面）
- 文件大小、修改时间清晰显示
- 批量选择操作（删除、移动、分享）

## 4. 文件分享功能（核心模块）

### 4.1 分享方式

| 分享类型 | 说明 |
|---------|------|
| 公开链接 | 无需密码，链接可直接访问 |
| 密码链接 | 生成随机密码，访问需输入密码 |
| 指定好友 | 仅指定账号可访问 |

### 4.2 分享设置

| 设置项 | 选项 |
|--------|------|
| 有效期 | 1天 / 7天 / 30天 / 永久 |
| 权限 | 仅查看 / 可下载 |
| 操作 | 取消分享、修改权限、查看分享记录 |

### 4.3 分享体验

- 分享链接一键复制
- 支持微信/QQ/邮件分享
- 无需登录即可预览（缩略图、基本信息）
- 下载需登录验证
- 好友分享文件快速保存至个人网盘

## 5. 备份与同步功能（核心模块）

### 5.1 手机备份

| 备份类型 | 说明 |
|---------|------|
| 相册自动备份 | 仅WiFi备份开关、可选原图/压缩图 |
| 视频自动备份 | 支持自动备份手机视频 |
| 备份进度 | 实时查看备份进度 |
| 去重机制 | 相同文件仅保留一份，提示覆盖或跳过 |
| 通知提醒 | 备份完成后推送通知 |

### 5.2 PC端同步

| 功能点 | 说明 |
|--------|------|
| 文件夹同步 | 指定本地文件夹，自动同步至网盘 |
| 双向同步 | 本地修改→网盘更新，网盘修改→本地更新 |
| 版本历史 | 支持恢复指定版本的备份文件 |
| 同步控制 | 暂停/继续同步，修改同步路径 |

## 9. 技术架构

### 9.1 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                     客户端层                            │
│   (移动端 iOS/Android | PC端 Electron | Web端)          │
├─────────────────────────────────────────────────────────┤
│                     网关层                              │
│              (负载均衡 | 路由分发)                       │
├─────────────────────────────────────────────────────────┤
│                     服务层                              │
│   ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐     │
│   │ 用户服务 │ │ 文件服务 │ │ 分享服务 │ │ 备份服务 │     │
│   └─────────┘ └─────────┘ └─────────┘ └─────────┘     │

```

### 9.2 技术选型

| 层级 | 技术栈 | 说明 |
|------|--------|------|
| 移动端 | Flutter | 跨平台开发，提升开发效率 |
| PC端 | Electron | 桌面应用框架 |
| Web端 | Vue3 + Vite | 响应式Web界面 |
| 后端框架 | Spring Boot / Node.js | RESTful API |
| 数据库 | MySQL | 用户信息、文件metadata、分享记录 |
| 缓存 | Redis | 会话管理、热点数据缓存 |
| 文件存储 | 本地存储 + 云存储 | 分片存储、去重存储 |

### 9.4 API 设计（核心接口）

#### 用户认证
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/auth/register | 用户注册 |
| POST | /api/auth/login | 用户登录 |
| POST | /api/auth/logout | 登出 |
| POST | /api/auth/refresh-token | 刷新Token |

#### 文件管理
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/files | 获取文件列表 |
| POST | /api/files | 上传文件 |
| PUT | /api/files/:id | 更新文件信息 |
| DELETE | /api/files/:id | 删除文件 |
| POST | /api/files/:id/move | 移动文件 |
| POST | /api/files/:id/copy | 复制文件 |
| GET | /api/files/search | 搜索文件 |

#### 分享管理
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/shares | 创建分享 |
| GET | /api/shares/:id | 获取分享信息 |
| DELETE | /api/shares/:id | 取消分享 |
| POST | /api/shares/:id/save | 保存分享文件 |

#### 备份管理
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/backups | 获取备份列表 |
| POST | /api/backups | 创建备份任务 |
| PUT | /api/backups/:id | 更新备份任务 |
| DELETE | /api/backups/:id | 删除备份任务 |

## 10. 项目实施计划

### 第一阶段：核心功能MVP（预计4周）

1. **用户系统**：注册、登录、认证
2. **文件上传下载**：基础上传、下载、断点续传
3. **文件管理**：列表、搜索、排序、收藏
4. **基础分享**：公开链接分享

### 第二阶段：完善功能（预计4周）

1. **回收站**：30天保留、恢复、彻底删除
2. **密码分享**：加密链接分享
3. **相册备份**：手机照片自动备份
4. **基础会员**：容量扩容

### 第三阶段：体验优化（预计3周）

1. **PC端同步**：文件夹双向同步
2. **在线预览**：文档、图片、视频预览
3. **安全加固**：文件加密、异常登录提醒
4. **性能优化**：传输效率、界面流畅度

### 第四阶段：发布与迭代（预计1周）

1. 测试与Bug修复
2. 文档完善
3. 正式发布
